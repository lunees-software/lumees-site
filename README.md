# Lunees — página "Em desenvolvimento"

Página estática única que fica no domínio enquanto o site novo é construído.

- `index.html`: página completa (HTML + CSS + JS inline)
- `assets/`: logo, favicons, fontes e GSAP (tudo local, sem CDN)

## Deploy (Cloudflare Pages)

- Production branch: `main`
- Framework preset: None
- Build command: vazio
- Build output directory: `/`

O site completo (Astro + Three.js) está na branch `mock-1`.
